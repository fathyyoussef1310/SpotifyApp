🎵 Spotify Clone App
✨ Features

🎨 Clean and modern Spotify-like UI ✔️

📱 Responsive design using flutter_screenutil ✔️

🔑 Login & Register screens ✔️

🏠 Home, Explore, Favorites, and Profile tabs ✔️ (Almost done)

🎶 Custom reusable widgets: buttons, text fields, colors, images

🌗 Dark theme interface ✔️

🎭 Custom app theme: Light & Dark modes ✔️

🌐 API integration to fetch real Quran data ✔️ (Used Cubit and Bloc)

⚡ State management using GetX for Themes and Authentication

🛠️ Tech Stack

Flutter & Dart

flutter_bloc, cubit for state management

GetX for reactive theme & auth management

flutter_screenutil for responsive layouts

Audioplayers / just_audio for audio playback

Login / Register

Explore & Favorites tabs
